이 사이트를 사장님(고객님) 계정으로 완전히 넘기는 과정입니다.
아래 4단계를 순서대로 따라와 주세요.

🧰 먼저 준비할 것 (무료)

  • 1
    GitHub 계정 — github.com 가입사이트 코드가 보관되는 곳
  • 2
    Vercel 계정 — vercel.com 에서 "GitHub로 가입" 권장실제로 사이트가 운영되는 곳(호스팅)
1

GitHub 저장소 이전 수락

고객님이 진행
  1. GitHub에 로그인합니다. (제작자가 이전 요청을 이미 보냈습니다)
  2. 가입한 이메일로 온 이전 안내 메일, 또는 GitHub 우측 상단 알림(🔔)에서 "baegwan119care 저장소 이전" 항목을 엽니다.
  3. 초록색 Accept transfer 버튼을 클릭합니다.
  4. 저장소 baegwan119care 가 고객님 계정으로 들어오면 완료입니다.
Tip. 메일이 안 보이면 GitHub 로그인 상태에서 알림 아이콘(🔔)을 확인해 보세요.
2

Vercel 가입 · 로그인

고객님이 진행
  1. vercel.com 접속 → Sign Up(가입)
  2. "Continue with GitHub" 선택 — 방금 그 GitHub 계정으로 연결합니다.
  3. 권한 요청이 나오면 승인(Authorize) 합니다.
중요. 반드시 1단계에서 저장소를 받은 그 GitHub 계정으로 Vercel에 가입해야 사이트를 불러올 수 있습니다.
3

사이트 불러와서 배포

고객님이 진행
  1. Vercel 대시보드 우측 상단 Add New → Project 클릭
  2. 목록에서 baegwan119care 저장소를 찾아 Import
  3. 설정은 그대로 두고 Deploy 클릭
  4. 잠시 후 임시 주소(○○○.vercel.app)로 사이트가 뜨면 성공입니다.
참고. 이 단계까지는 기존 주소(baegwan119care.co.kr)가 계속 정상 작동합니다. 도메인은 다음 단계에서 옮깁니다.
4

도메인 연결 (제작자와 함께)

제작자 ↔ 고객님
  1. 도메인은 한 번에 한 곳에만 연결됩니다. 진행 전 제작자에게 "도메인 옮기겠습니다"라고 알려주세요.
  2. (제작자) 기존 Vercel에서 baegwan119care.co.kr 을 제거(Remove)
  3. (고객님) 내 Vercel 프로젝트 → Settings → Domains → baegwan119care.co.kr 입력 → Add
  4. 대부분 그대로 "Valid ✅" 로 연결됩니다. (보안접속 https는 자동 발급)
  5. https://baegwan119care.co.kr 에 접속해서 내 사이트가 뜨는지 확인하면 끝!
안내. 2~4번은 몇 분 안에 이어서 진행하는 게 좋습니다. 그 사이 잠깐 접속이 불안정할 수 있어요.

🎉 이전 완료!
