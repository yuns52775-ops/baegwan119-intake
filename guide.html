구글시트 연동
설정 안내

홈페이지에서 고객이 상담신청을 하면, 그 내용이 사장님 구글시트에 자동 저장 + 이메일로 알림이 오도록 설정하는 방법입니다. 아래 순서대로 따라 하시면 됩니다.

약 5분 소요 무료 · 프로그램 설치 없음 구글 계정만 필요
가장 중요: 마지막 7단계에서 나오는 웹 앱 URL을 꼭 담당자에게 보내주세요. 그래야 홈페이지와 연결됩니다.

구글시트 새로 만들기

인터넷 주소창에 sheets.new 를 입력해 빈 구글시트를 엽니다. (구글 로그인 필요) 시트 이름은 배관119케어 상담신청 등 편하게 정하세요.

Apps Script 열기

상단 메뉴에서 확장 프로그램 → Apps Script 를 클릭합니다. 새 탭에 코드 입력 화면이 열립니다.

코드 붙여넣기

기존에 있던 내용은 모두 지우고, 아래 코드를 복사해서 붙여넣습니다. 그리고 맨 윗줄 이메일을 사장님이 알림 받을 주소로 바꿔주세요.

Apps Script 코드
// ===== 배관119케어 상담신청 접수 =====
const NOTIFY_EMAIL = "여기에_알림받을_이메일@gmail.com"; // ← 이 주소만 바꾸세요

function doPost(e){
  try{
    var p = (e && e.parameter) ? e.parameter : {};
    var ts = new Date();
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    if (sheet.getLastRow() === 0){
      sheet.appendRow(["접수시각","성함","연락처","지역","작업종류","증상/희망시간"]);
    }
    sheet.appendRow([ts, p.name||"", p.phone||"", p.area||"", p.type||"", p.memo||""]);
    MailApp.sendEmail(
      NOTIFY_EMAIL,
      "[배관119케어] 새 상담신청 · " + (p.name||"") + " " + (p.phone||""),
      "■ 성함: "+(p.name||"")+"\n■ 연락처: "+(p.phone||"")+"\n■ 지역: "+(p.area||"")+
      "\n■ 작업종류: "+(p.type||"")+"\n■ 증상/희망시간: "+(p.memo||"")+"\n■ 접수시각: "+ts
    );
    return ContentService.createTextOutput(JSON.stringify({ok:true})).setMimeType(ContentService.MimeType.JSON);
  }catch(err){
    return ContentService.createTextOutput(JSON.stringify({ok:false,error:String(err)})).setMimeType(ContentService.MimeType.JSON);
  }
}

저장하기

상단의 저장 아이콘(💾) 을 누르거나 Ctrl+S 로 저장합니다.

배포하기

우측 상단 배포 → 새 배포 를 누르고, 아래처럼 설정합니다.

  • 유형(톱니바퀴 ⚙️) → 웹 앱 선택
  • 실행 계정 → 나
  • 액세스 권한 → 모든 사용자 (꼭 "모든 사용자"! "나만" 이면 작동 안 함)
  • 배포 버튼 클릭

권한 승인

처음이면 권한 요청 창이 뜹니다. 본인 구글 계정 선택 → "이 앱은 확인되지 않았습니다" 경고가 나오면 고급 → (안전하지 않은 페이지)로 이동 → 허용 을 눌러주세요. (본인이 만든 스크립트라 안전합니다)
